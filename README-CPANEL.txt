MAAN WORLD HOSPITALITY — CPANEL STATIC HTML/CSS VERSION

This package is converted from the uploaded Lovable project into static HTML + CSS + JavaScript. It does not require React, TypeScript, TanStack Router, Tailwind, Vite, Node.js or npm on the server.

UPLOAD TO CPANEL
1. cPanel → File Manager.
2. Open public_html (or the document root of your domain).
3. Upload this ZIP and Extract it.
4. Ensure index.html is directly inside public_html.
5. Open your domain.

Included pages: Home, About, Services, Hospitality Staffing, Chef Staffing, Hotel Manpower, Restaurant Manpower, Event & Catering Staffing, Industries, Why Choose Us, For Employers, For Job Seekers, Contact, plus 404.

Original project images are included in /assets.

IMPORTANT: The original Lovable source contains placeholder contact details. Replace +91 00000 00000, info@maanworldhospitality.com and the placeholder address before launch.

The manpower form has client-side validation and the same success-state concept. To actually receive submissions by email, connect it to a PHP endpoint or form service on cPanel.
